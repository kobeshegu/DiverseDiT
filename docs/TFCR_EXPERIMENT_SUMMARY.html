Paired Trajectory Supervision: What Is Actually Working

截至当前实验，最稳定的收益来自高比例 paired trajectory 训练，尤其是 paired same-step REPA。J7-J10 已完成：late-start dynamic clean 在 U0 上给出更好的单次 FID，但仍需要 seed repeat 才能确认 additive gain。

5. 实验族分析

External target

U0 paired REPA 是当前主线

U0 删除 A5 factor losses，仅保留 paired same-step REPA，仍以三种子均值 22.82 显著优于 A2 REPA mean 27.77。matched seed 改进为 4.82 到 5.11 FID；J10 单次进一步到 22.60，但未做 seed repeat。

No external teacher

A5 仍是最好的 teacher-free 结果

A5 ratio 1.0 为 29.83，A3 paired two-view 为 30.11。显式 decomposition 的增益只有约 0.28 FID，主要收益来自 dense paired trajectory supervision。

EMA teacher

SF2 接近 A5，但不是新最优

SF2 为 29.89，SF3 为 30.16，SF4 shuffled 为 30.20。source injection 有小收益，但 shuffled teacher 接近，source correspondence 因果性不强。

Dynamic self-guidance

late dynamic clean 值得复验

无 REPA 的 J1-J5 不支持当前 dynamic self-guidance；但叠到 U0 后，J7-J10 都低于 U0 mean，J9/J10 表明 100k 后启动比从头施加强。

6. 现在应该如何描述方法和 insight

最稳妥的论文叙事不是“我们已经证明显式 decomposition 是主收益来源”，而是：

Paired trajectory supervision creates a stronger representation-guided diffusion training signal. 对同一样本的不同 trajectory/noise views 使用共享 clean semantic target，能迫使模型学习跨 view 的 shared source knowledge，同时保留每个 view 自己的 FM velocity 预测。

与 REPA/SRA/Self-Flow 的关系

  • REPA：提供外部 clean semantic target；U0 证明 paired same-step REPA 比单视图 REPA 强得多。
  • SRA / Self-Flow：EMA/internal teacher 思路在当前实现里接近 A5，但没有超过；shuffled teacher 控制削弱了 source-correspondence causality。
  • TFCR decomposition：在 no-external-teacher setting 有小增益，但不是当前最主要来源；它更适合作为解释/机制模块，而不是唯一 headline。
  • Dynamic clean target：无 REPA 的 J1-J5 不够强；叠到 U0 后 J7-J10 有一致正信号，尤其 late start，但仍需 seed repeat 才能证明它是稳定 additive 机制。

可写入 proposal 的谨慎 statement

可以写暂时不要写
Dense paired trajectory views are a robust source of gain.Explicit decomposition is the primary cause of the best FID.
Paired REPA strongly improves over standard REPA at matched seeds.Teacher-free self-guidance already replaces external representation targets.
Late-start dynamic clean regularization is a promising U0 add-on.Dynamic clean consensus has confirmed additive benefit beyond seed variance.
Direct hidden-state pair mixing is unsafe across different timesteps/noise.Any pair interaction will help if made strong enough.

8. 下一步优先级

P0
补 J10/J9 seed repeat。 J10 现在是最值得验证的 dynamic-clean 版本，J9 用来判断 hard/confidence filtering 是否真的必要。
P1
保留 U0 paired REPA 作为 validated main line。 当前 U0 三种子已有稳定优势；任何新方法必须通过同样标准。
P2
将主线 narrative 调整为 paired representation guidance + optional late dynamic clean。 明确 A5 decomposition 是 teacher-free 机制探索，不是当前最佳结果来源。
P3
机制图优先做 source/timestep/noise probes。 目标是证明 paired supervision 和 late dynamic clean 是否提升 shared source knowledge，而不是只增加算力。
