Trajectory Factorization via Cross-View Recomposition（TFCR）：把扩散轨迹表征分解为可跨视图交换的 Persistent factors 与描述当前状态的 Evolving factors。

Branch: codex/persistent-evolving-recomposition Backbone: SiT / DiverseDiT Primary benchmark: ImageNet 256×256 Default extra compute: ≈1.5×

1. 核心论点

现有 representation-guided diffusion 方法主要回答“跨 corruption 应该保留什么”；TFCR 进一步把“必须随 diffusion state 变化什么”变成显式 representation objective。

Paper thesis：Diffusion trajectory 天然提供有序、连续、可控的 paired views。Cross-view recomposition 能把 invariance-only alignment 未组织的变化信息转化为有效监督，并给出理解 REPA、SRA、Self-Flow 的共同坐标系。

目标贡献

  1. 提出“Persistent + Evolving”扩散轨迹表征视角。
  2. 用交换与重组性质定义分解，而非预设 structure / semantics / texture。
  3. 证明显式学习 what changes 带来超越 invariance-only 和 matched-view compute control 的收益。
  4. 通过 probe、swap intervention、noise/timestep sensitivity 揭示 REPA、SRA、Self-Flow 学到什么。

2. REPA / SRA / Self-Flow 的统一 Insight

REPA

External persistence

将 noisy hidden state 投影到 clean-image DINO 表征。直接监督的是跨噪声保留的信息，其语义基底由外部 encoder 指定。

SRA

Internal persistence

用 deeper + lower-noise + EMA feature 指导 shallow + higher-noise feature。教师来源改变，但原语仍是向稳定、更强目标对齐。

Self-Flow

View augmentation

heterogeneous timesteps 制造信息不对称。后续 attention-separation 结果提示，收益很大部分来自 noise-space augmentation，而不只来自跨 token 信息传递。

REPA / SRA / Self-Flow ≈ construct corruption views → strengthen shared / persistent representation

它们没有显式要求 intermediate state-specific information 具有互补性、有序性或可重组性。Flow matching 只要求最终 velocity 正确，不能保证中间层的变化因素被组织起来。

需要用实验验证，而不是预写成结论：REPA 应更偏 semantic persistence；SRA 应偏向内部 cleaner/deeper target；Self-Flow 应增加 noise/timestep view coverage；TFCR 的 Evolving branch 应保留当前 state 所需的 sample-specific 条件信息。

3. 方法：Trajectory Factorization via Cross-View Recomposition

3.1 可控 paired views

x_a = α(t_a)x₀ + σ(t_a)ε_a    |    x_b = α(t_b)x₀ + σ(t_b)ε_b
  • same-ε：只改变 t，形成严格同轨迹视图。
  • cross-ε：同时改变噪声 realization，迫使 Persistent 排除 trajectory leakage。
  • mixed：默认 50% cross-ε，兼顾轨迹演化和噪声泛化。

L_p = ½[d(p_a, sg(p_b)) + d(p_b, sg(p_a))]
ĥ_a = R(p_b, e_a), ĥ_b = R(p_a, e_b)
L_r = NMSE(ĥ_a, sg(h_a^n)) + NMSE(ĥ_b, sg(h_b^n))

Persistent 可以交换；Evolving 必须来自当前 view。重组器默认不接收原始 timestep，避免最直接的 e_t = MLP(t) shortcut。目标是 stop-gradient 的 deeper normalized feature，而非像素重建。

3.3 可选有序演化

ê_b = T(e_a, t_b - t_a), ê_a = T(e_b, t_a - t_b)
L_t = d(ê_b, sg(e_b)) + d(ê_a, sg(e_a))

Transition predictor 只有在 minimal TFCR 已显著优于 Inv-only 后才进入主模型，避免方法复杂度先于核心证据。

3.4 训练成本与调度

主 batch 每个 source 始终有一个 FM view，仅比例 r 的 source 增加第二个 view，因此 backbone 成本约为 1+r。默认 r=0.5，约 1.5×；辅助目标 10k warmup，250k–400k cosine decay，400k 后停止额外 view 计算。

L = L_FM + λ_REPA L_REPA + s(step)[λ_p L_p + λ_r L_r + λ_t L_t + optional regularizers]

不能声称

8. Reviewer 风险与预防

“只是 two heads / invariant-equivariant 老概念”
贡献钉在 diffusion trajectory、cross-view exchangeability、current-view recomposition 和 generation mechanism evidence；引用 SIE 和 timestep-specific representation，主动划清边界。
“收益只是额外算力或两个噪声视图”
A3 使用完全相同的 batch ratio、frequency、sampler、warmup/decay和训练步数；同时绘制 FID–step 与 FID–FLOP。
“Evolving 只会复制 timestep”
重组器不接 raw t；使用 cross-ε；做 t-only replacement、ε regression、same-t/cross-ε intervention。
“重建并不能证明 disentanglement”
不声称统计独立；将分解定义为 operational factorization，并用 swap、branch necessity 与 counterfactual probe 支撑。
“Evolving 可以承载全部信息，Persistent 被重组器忽略”
这是当前目标真实存在的可辨识性风险，而不是已被理论排除的情况。把 zero-P / zero-E replacement、容量扫描、分支梯度与线性 probe 设为主结果的门槛；若 P 无必要性，则在扩大训练前加入 Persistent-only common-target objective 或 branch-usage bottleneck。
“Self-Flow 已经学习变化”
比较 dual-view FM、attention separation 与 explicit recomposition，区分数据增强和 shared/private supervision。
